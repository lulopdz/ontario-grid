# ontario-grid

Datos públicos del mercado eléctrico de Ontario, tomados de los reportes públicos de IESO: precios
day-ahead y real-time por zona, generación por fuente, demanda real contra pronóstico,
interconexiones y adecuación.

Sitio: https://lulopdz.github.io/ontario-grid/

Proyecto independiente, sin afiliación con IESO.
